# Project Context

## Identity

- Working title: Astral
- Repository: https://github.com/youssef-011/SpaceGame
- Engine: Unity 6
- Language: C#
- Target platform: Windows PC
- Genre: 2D pixel art platformer
- Perspective: 2D side view
- Team size: 2 developers

## Purpose

Astral is primarily a learning and portfolio project. Commercial success is not the first priority. The project should teach professional software engineering practices while growing into a polished, small-scale game.

## Vision

The player is an astronaut who unexpectedly crashes onto a mysterious abandoned planet. Progress is about more than finishing levels: the player gradually learns what happened to the planet while searching for a way back home.

The experience should feel nostalgic, mysterious, lonely, peaceful, slightly melancholic, vintage, and aesthetic.

## Scope

The target scope is approximately six handcrafted chapters. Each chapter should introduce one new gameplay mechanic and increase difficulty gradually.

Small polished experience beats large unfinished project.

## Gameplay Pillars

- Responsive platforming
- Fair challenge design
- Simple combat
- Light exploration
- Environmental storytelling
- Reusable systems and maintainable code

## Non-Goals

- No RPG mechanics
- No inventory
- No crafting
- No leveling system
- No skill tree
- No unnecessary complexity
