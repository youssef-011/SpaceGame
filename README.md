# Astral

Astral is a 2D pixel art platformer built in Unity 6 for Windows PC.

The player controls an astronaut who crash-lands on a mysterious abandoned planet and slowly uncovers what happened there while searching for a way home. The project is intentionally scoped as a small, polished learning project for two developers, with maintainable software engineering practices treated as a core goal.

## Project Goals

- Build a portfolio-quality 2D platformer with a focused scope.
- Practice professional software engineering habits in a real Unity project.
- Keep systems readable, reusable, and easy to extend.
- Prefer a complete, polished experience over a large unfinished one.

## Game Direction

- Genre: 2D side-view pixel art platformer.
- Platform: Windows PC.
- Players: Single player.
- Tone: nostalgic, mysterious, lonely, peaceful, melancholic, vintage.
- Visual style: retro space pixel art with dark backgrounds, purple and blue tones, and warm orange highlights.
- Audio style: ambient music, soft environmental sounds, minimal retro UI feedback.

## Core Gameplay

The intended gameplay loop is exploration, fair platforming challenges, simple combat, story discovery, checkpoints, and chapter completion.

Planned movement abilities include walking, running, jumping, dashing, wall sliding, wall jumping, and future double jumping.

Combat should remain simple. The game should not include RPG systems, inventory, crafting, leveling, or skill trees.

## Repository Layout

- `.github/` - GitHub-related project configuration.
- `Assets/` - Unity project assets when the Unity project is created.
- `Docs/` - Human-facing project documentation.
- `Unity/` - Unity-specific notes, exports, or supporting project material.
- `context/` - Compact project context for developers and AI assistants.
